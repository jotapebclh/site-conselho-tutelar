# Site Conselho Tutelar

Prototipo academico de site institucional e informativo sobre Conselho Tutelar, pensado para orientar familias e responsaveis e servir como base para uma versao final em WordPress.

## Como Ver O Site

Abra o arquivo `index.html` no navegador.

Opcao recomendada durante o desenvolvimento: usar a extensao Live Server no VS Code e abrir `index.html` com `Open with Live Server`.

## Estrutura

- `index.html` — pagina inicial.
- `pages/` — paginas internas do site.
- `assets/css/styles.css` — estilos globais.
- `assets/js/main.js` — menu responsivo.

## Paginas Do MVP

- Inicio
- Sobre
- Quando procurar
- Direitos
- Rede de apoio/CRAS
- Contato

## Observacao

Campos entre colchetes, como `[telefone do Conselho Tutelar]`, devem ser substituidos por dados oficiais antes de qualquer publicacao.
